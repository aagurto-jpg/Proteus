AXIS-Y: Proteus (IB Chemistry) — private edition / edición privada

ESPAÑOL
1. En GitHub crea un repositorio PÚBLICO nuevo, por ejemplo "Proteus".
2. "Add file → Upload files": sube index.html, app-part1.bin y manager.html (sin carpetas).
3. Settings → Pages → "Deploy from a branch" → main, / (root) → Save.
4. Espera el check verde en Actions. Enlace: https://TU-USUARIO.github.io/Proteus/
5. Entra con tu código de profesor y usa el botón 🔑 Códigos para agregar alumnos (7 días, 2 semanas, 30 días, hasta el examen o fecha personalizada) y publicar en GitHub con tu token.
6. Para actualizar: reemplaza index.html y app-part1.bin y abre el enlace con ?v=2 (luego ?v=3…).
Los códigos creados en el panel viven dentro de index.html: si subes un index.html nuevo, vuelve a crearlos.

ENGLISH
1. Create a new PUBLIC GitHub repository, e.g. "Proteus".
2. Upload index.html, app-part1.bin and manager.html (flat).
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. Wait for the green tick in Actions. Link: https://YOUR-USER.github.io/Proteus/
5. Sign in with the teacher code; use 🔑 Codes to add students and publish with your GitHub token.
6. To update: replace index.html and app-part1.bin, then open the link with ?v=2.
