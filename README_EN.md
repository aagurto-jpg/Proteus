# AXIS-W: Gaia (IB ESS) — private edition
Developed by Mr. A. Agurto, 2026 V1.0

Upload these 2 files to a public GitHub repository (for example `Gaia`):
`index.html` and `app-part1.bin`. Do NOT upload `manager.html` (manage codes from the 🔑 Codes button inside the app). Then Settings → Pages → Deploy from branch → `main` / root.

Everything (questions, cards, markschemes, case studies) is encrypted inside `app-part1.bin`.
Nobody can open the app without a valid access code, even with the GitHub link.

Managing codes: open the app with the teacher code → tap **🔑 Codes** → add a student, choose how long
the access lasts → **Publish to GitHub** (paste a fine-grained token with *Contents: read and write* on this repo
the first time). Students reload the page and their code works within a minute or two.
Never upload `codes.json` or the teacher-code file.
