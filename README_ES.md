# AXIS-W: Gaia (IB SAS) — edición privada
Desarrollado por Mr. A. Agurto, 2026 V1.0

Sube estos 2 archivos a un repositorio público de GitHub (por ejemplo `Gaia`):
`index.html` y `app-part1.bin`. NO subas `manager.html` (gestiona los códigos desde el botón 🔑 Codes dentro de la app). Luego Settings → Pages → Deploy from branch → `main` / raíz.

Todo el contenido (preguntas, tarjetas, esquemas, casos) está cifrado dentro de `app-part1.bin`.
Nadie puede abrir la app sin un código válido, aunque tenga el enlace de GitHub.

Gestionar códigos: abre la app con el código de profesor → toca **🔑 Codes** → agrega un alumno, elige cuánto
dura su acceso → **Publish to GitHub** (la primera vez pega un token fine-grained con *Contents: read and write*
sobre este repositorio). Los alumnos recargan la página y su código funciona en uno o dos minutos.
Nunca subas `codes.json` ni el archivo con el código de profesor.
